# Statistical Analysis

Guidance for statistical analysis of simulation and observational data tables.

## Instructions

- Always report the sample size N alongside every statistic.
- Give uncertainties to one significant figure, values matched to the uncertainty's decimal place.
- State whether errors are statistical or systematic.
- Prefer robust estimators (median, MAD) for small samples (N < 30).
- For fits, report chi-squared per degree of freedom and the covariance matrix diagnostics.
